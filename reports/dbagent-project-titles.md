# DB-Agent 简历项目标题备选

| 序号 | 简历项目标题 | 一句话定位 |
|---:|---|---|
| 1 | 手动实现面向业务数据库的 Text2SQL Agent | 面向 OneDBA 业务库打通自然语言问题、Agent 工具调用、schema 理解、SQL 生成校验和只读执行链路。 |
| 2 | DB-Agent：基于工具调用的数据库问答 Agent 工程实践 | 将找库、找表、查表结构、生成 SQL 和执行查询封装为可被 Agent 调用的数据库工具链。 |
| 3 | 面向 OneDBA 的 Text2SQL Agent 后端服务 | 基于 FastAPI/SSE 实现自然语言查库后端，支持会话管理、流式返回、SQL 展示和查询状态持久化。 |
| 4 | 手写 ReAct 到 deepagents 的数据库 Agent 演进实践 | 围绕数据库查询场景实践 Agent 运行层演进，在保留业务工具和 SQL 安全边界的同时降低循环维护成本。 |
| 5 | HDC 增强的业务库 Text2SQL Agent | 通过离线生成数据库 schema 语义上下文并在线召回注入，降低陌生业务库下的找表和字段理解成本。 |
| 6 | 带 SQL Memory 的数据库查询 Agent | 记录历史成功查询的问题、SQL 和执行摘要，通过相似 SQL 模式召回辅助新问题的 SQL 生成。 |
| 7 | 面向真实业务库的 NL2SQL 工程链路实现 | 手动实现从用户问题、schema 检索、SQL 生成、validator 校验、失败修复到 OneDBA 查询执行的完整链路。 |
| 8 | 数据库 Agent 的工具编排与安全执行实践 | 以数据库工具调用为核心，加入只读约束、DDL 拦截、字段校验、LIMIT 控制和执行反馈修复。 |
| 9 | 可评测的 Text2SQL Agent 后端原型 | 构建覆盖 SQL 正确性、表/列引用、过滤条件、结果正确性、工具调用、token 和延迟的 Agent 评测闭环。 |
| 10 | 面向 AI 应用后端岗位的数据库问答 Agent 项目 | 以数据库问答为业务场景，综合实现 LLM API 接入、Agent Workflow、上下文管理、后端 API、Docker 部署和管理界面。 |

## 推荐优先级

| 推荐级别 | 标题 | 适合投递方向 |
|---|---|---|
| 首选 | 手动实现面向业务数据库的 Text2SQL Agent | AI 应用开发、Agent 开发、大模型应用后端 |
| 次选 | DB-Agent：基于工具调用的数据库问答 Agent 工程实践 | Agent 工程、工具调用、业务系统集成 |
| 次选 | 面向 OneDBA 的 Text2SQL Agent 后端服务 | 大模型应用后端、AI 应用工程化 |
| 技术取舍突出 | 手写 ReAct 到 deepagents 的数据库 Agent 演进实践 | Agent Runtime、框架适配、工程化实践 |
| 评测突出 | 可评测的 Text2SQL Agent 后端原型 | 评测 Infra、Agent 质量评估、LLMOps 入门方向 |
